## 1. M14 implementation (commit `9026f96`)

### Name collection (`internal/css/names.go`)

- `css.CollectNames(nodes) Names{Classes, IDs, Keyframes}` walks the
  **resolved** node tree (post-@extend, post-merge) so the result mirrors the
  rendered CSS:
  - Rules: skipped when `!hasOutput()` (empty bodies, unextended
    placeholders); scans own `Selectors` (unless `Placeholder`), `Extenders`
    (an `@extend`er with no own body appears only here), and `Duplicates`'
    selectors (MergeDuplicates mode).
  - Selector scan: rune loop pulling `.class` / `#id` idents; **skips quoted
    strings and `[attr]` blocks** (`[href$=".png"]` must not yield class
    `png`); `\` escapes never start a name; idents are
    `[-_a-zA-Z\x80+][-_a-zA-Z0-9\x80+]*`.
  - Keyframes: header parsed via `strings.Cut` on the first space so
    **quoted names with spaces** work (`@keyframes "slide in"`); matches any
    `@…keyframes` prefix (vendor forms). Body not descended (steps carry no
    names).
  - All lists sorted + deduped → diff-stable generated files.

### Extraction (`internal/eval/extract.go` + refactor)

- Refactored `evalNodes` to return `(*evaluator, []css.Node, error)` (was
  nodes+deps) so callers can reach `ev.rootScope`; `EvaluateFull` takes deps
  from `ev.deps`.
- `eval.ExtractManifest(sheet, opts)` = evalNodes + CollectNames + root-scope
  vars: `ev.rootScope.vars` only (funcs live in a separate map — mixins
  excluded for free; **rule-local vars excluded** since they bind in child
  scopes). Values rendered `value.Deref(v).CSS(true)` — Deref makes
  CustomProperties-wrapped tokens come out concrete (`#0af`, not
  `var(--primary)`). Vars sorted by name.

### Public API (`gen.go` in root package)

- `styl.Var{Name, Value}`; `styl.Manifest{Source, Classes, IDs, Keyframes,
  Vars}`; `Extract(src, opts)` / `ExtractFile(path, opts)` (sets
  `Manifest.Source`; honors FS/Globals/IncludePaths like Compile; forces
  Pretty=true internally for readable var values).
- `Manifest.GoSource(pkg)` → `format.Source`-formatted file:
  - Header `// Code generated by styl gen from <src>; DO NOT EDIT.` + package
    doc + one `const (…)` block per non-empty group.
  - Mangling `goName`: split on non-alphanumerics, title-case segments
    (`card__title--big` → `CardTitleBig`); leading digit → `N` prefix
    (`3col` → `N3col`); underscores are separators (NOT letters — a `_`
    treated as a letter would swallow the segment-start and emit an
    unexported ident).
  - Suffixes prevent cross-group shadowing: classes bare, IDs `ID`, keyframes
    `Anim`, variables `Var` (value = compile-time CSS value, `// name`
    comment carries the original var name).
  - Collisions tracked globally across all four groups → error naming both
    sources (e.g. class `primary-var` vs variable `primary` →
    `PrimaryVar`). Empty-after-mangle names and invalid pkg names error;
    pkg defaults to `css`.
- Errors via `serr.F(...)` / single-field `serr.Wrap(err, "msg…")` (v1.3.0's
  fixupFields turns a lone field into `msg`).

### CLI (`cmd/styl/gen.go`)

- Subcommand dispatch: `os.Args[1] == "gen"` → own FlagSet
  (`-o`, `-pkg` default `css`, repeatable `-D name=value`); stdout by
  default. go:generate wiring documented:
  `//go:generate go run github.com/rohanthewiz/go-styl/cmd/styl gen -pkg css -o css_gen.go app.styl`

## Carry-forward notes

- `evalNodes` now returns the evaluator — any future "compile + inspect"
  feature (Prune, Component, LSP hover) should hook there rather than adding
  parallel eval paths.
- Generated-file naming contract is **frozen** once users generate: bare
  classes, `ID`/`Anim`/`Var` suffixes, `N` digit prefix, collision = error.
  Changing mangling later breaks user builds — treat as public API.
- `Manifest` lists are sorted (not source-order) deliberately: stable diffs
  under rule reshuffling.
- `styl gen -D` semantics mirror M13: a sheet `=` beats the flag; document
  `?=` when users report "my -D didn't take".
